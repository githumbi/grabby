The toolbar's close button now collapses it into a round button in the bottom-right corner, with the comment count on it, instead of removing it. One click (or Alt+G) opens the toolbar again. It stays collapsed when the reviewer moves to another page in the same tab, and comments keep sending while it is collapsed. Finish review is unchanged, and `hideToolbar()` / `hide()` still remove the toolbar completely.
